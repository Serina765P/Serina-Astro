# 媒体、授权与前台交互改进

日期：2026-10-30。本文记录已确认的需求与验收边界，不替代各实施票据的可复现步骤。

## 已确认决策

- 保持 Astro 静态站点与现有莫兰迪/编辑式视觉；借鉴 Nuxt UI 的语义 token、交互状态、组件与无障碍规范，不迁移 Nuxt、不把后台样式机械复制到前台。
- 网易云自定义播放器候选为 Video.js 10 + 可替换数据适配层。固定全站歌单为 `8562312822`，手动播放，站内导航尽量保持连续。
- 公共 Meting 目前只通过歌单读取，不代表音乐可播：浏览器抽查首、中、尾曲目，音频 URL 均为 404。网易云数据源尚未验收，不得以该接口直接实施。
- B 站使用官方 `https://player.bilibili.com/player.html` iframe，只要求 BV 号与从 1 开始的 `p`；不传 `aid` 或 `cid`，不调用 pagelist。实测真实博客源和本地文件可加载，`autoplay=0`。
- 文章音乐/视频开始时暂停全站 BGM，停止或结束不自动恢复。加载或播放失败展示可操作的提示与原平台链接。
- 根代码许可证为 MIT，署名 `芹菜P`，项目起始年 2025。原创文章只有 frontmatter `license: original` 才显示 CC BY-NC-SA 4.0；其他文章不显示 CC，历史文章不得自动批量推断。第三方素材、引用、翻译、字体与依赖另有其权利与许可。
- 修复已复现的桌面 TOC 横向溢出，并检查主要页面的响应式布局、焦点、键盘和减少动态效果。返回顶部在普通手机文章页未复现越界，需继续检查其他状态，不声称已经修复。

## 实施顺序与阻塞

1. **网易云数据源验证**：阻碍全站 BGM 和文章内自定义网易云播放器。要求固定歌单及代表性文章媒体的浏览器可播放证据、失败状态与第三方请求边界。若无可靠纯静态方案，回到用户选择官方 iframe 或接受自部署/其他数据服务，不能静默更换。
2. **B 站文章播放器**：不阻塞；提供 MDX 组件，BV/p 参数校验、响应式尺寸、标题、懒加载、原视频链接、与 BGM 的播放协调。
3. **代码与文章授权**：不阻塞；MIT LICENSE、README 范围说明、原创文章 frontmatter 与 CC 页脚、后台写作支持；历史文章仅由用户明确确认后标记。
4. **前台交互与缺陷修复**：不阻塞；先复现并修复 TOC 6px 横向溢出，检查移动端控件、溢出、焦点与减少动态效果，保持现有视觉身份。
5. **网易云媒体组件**：被第 1 项阻塞；验证通过后实现 Video.js 10 的自定义音频 UI、歌单与文章嵌入、生命周期、失败回退和跨页播放。
